# 복싱 셀프코치 PRD (최종본)

## 1. 문제 정의
- 한 줄 요약: 장비(미트) 없는 복싱 수업에서, 학생이 **자기 태블릿을 바닥에 세워 두고 혼자** 가드 자세를 실시간으로 점검받고, 신호에 반응하는 섀도복싱을 하며, 차시마다 자기점검 기록을 남긴다.
- 지금은 어떻게 하나(Before):
  - 자세 교정을 교사가 한 명씩 말로 해 줘야 해서, 학생 수에 비해 피드백이 부족하다.
  - 섀도복싱이 "정해진 순서대로 따라 하기"에 머물러, 보고 판단해서 움직이는 요소가 없다.
  - 차시별 성장 기록이 남지 않아 수행평가 근거가 약하다.

## 2. 대상 사용자
- 누구: 중학생 (학년 미정 → 8번), 교사는 진행만 하고 앱은 학생이 직접 조작
- 규모/맥락: 한 학급 약 25~30명, **학생 1인 1대 Windows 태블릿 PC**, 체육관
- 사용 방식: **모든 활동을 개인이 혼자**, 태블릿은 **바닥에 세워 둔 상태**로 사용 (짝 활동 없음)

## 3. MVP 기능 (3개)

### 기능 1: 가드 체크 (1차시 핵심)
**설치**
- 태블릿을 바닥에 세워 화면이 위쪽을 살짝 올려다보게 둔다.
- 학생은 약 2.5~3m 떨어진 바닥 표시 자리에 선다. 머리~허벅지가 화면에 들어오면 된다.
- 설치 확인 화면: 인식된 관절 점(코, 어깨, 팔꿈치, 손목, 엉덩이)을 보여 주고, 모두 잡히면 다음으로 넘어간다.

**내 가드 등록 (3초)**
- 화면에 바른 가드 예시 그림을 띄우고 "3, 2, 1" 카운트다운 후 3초간 자세를 수집한다. (초당 약 15회, 약 45회)
- 어깨너비를 1로 놓은 비율로 측정한다: 손 높이(어깨선 대비), 손-얼굴(코) 거리, 팔꿈치 벌어짐(몸통 옆선 대비)
- 45회 측정의 **중간값**을 학생 본인 기준으로 저장한다. (바닥 각도 왜곡·체격·거리 차이 보정)
- 등록 거부 조건과 피드백
  - 3초 동안 자세가 크게 흔들림 → "움직이지 말고 다시 해 주세요"
  - **최소 기준** 미달 → 부위를 짚어 안내하고 해당 관절 점을 빨갛게 표시
    - 손목이 어깨선보다 낮음 → "왼손(오른손)이 낮아요"
    - 손이 얼굴에서 멀리 떨어짐 → "왼손(오른손)을 얼굴 가까이"
    - 팔꿈치가 몸통에서 크게 벌어짐 → "왼(오른) 팔꿈치가 벌어졌어요"
- 매 차시 시작 때 다시 등록한다. (태블릿 위치가 매번 달라지므로)
- 등록 중 안내 글은 화면 **왼쪽 패널**에, 카운트다운 숫자는 **오른쪽**에 둔다. 가운데(학생이 서는 자리)는 비워 학생이 자기 모습을 보며 자세를 잡게 한다.

**라운드 판정**
- 라운드 시간: 30 / 60초 선택
- 두 가지를 모두 지켜야 가드로 판정한다.
  - 손: 개인 기준보다 어깨너비 0.3배 이상 내려가지 않음 (초기값)
  - 팔꿈치: 개인 기준보다 어깨너비 0.15배 이상 벌어지지 않음, 개인 기준과 상관없이 0.4배를 넘지 않음 (교사 테스트 후 0.25 → 0.15로 좁힘)
  - 위 개인 기준과 별도로 **최소 기준도 항상 함께 검사**한다. (손이 어깨 아래면 무조건 무너짐)
- **1초 유예**: 무너진 상태가 1초 넘게 이어질 때만 경고한다. (잽 후 복귀 시간 허용)
- 경고: 화면 테두리 초록 → 빨강, 화면 아래쪽에 "손 올려!" 또는 "팔꿈치 붙여!"(손·팔꿈치를 가리지 않게), 틀린 관절 점 빨강. 소리는 끄기가 기본, 켜기 옵션.
- 판정 보류: 관절이 화면 밖이거나 인식이 불확실하면 경고 대신 "상체가 다 보이게 서 주세요" 안내 (틀린 경고보다 경고하지 않는 쪽을 택함)
- 결과 화면: 손 유지율, 팔꿈치 유지율, 가장 오래 무너진 시간, 다시 하기 버튼

### 기능 2: 섀도 반응 콜러 (라운드 타이머 포함)
- 화면 전체 색과 화살표로 신호를 준다. 빨강 = 잽(앞손), 파랑 = 스트레이트(뒷손 쭉 뻗어 치기), 빨강·파랑 반반 + "원투" 글자 = 원투(잽 + 스트레이트), ←/→ = 좌우 슬립, ↓ = 더킹
- 레벨: 1단계 잽·스트레이트 단타 → 2단계 원투 중심(잽·스트레이트·원투 혼합) → 3단계 공격·방어 혼합
- 모든 신호에 동작 이름(잽, 스트레이트, 원투, 슬립, 더킹)을 크게 함께 표시 (2~3m 거리에서 읽히는 크기, 색 구별이 어려운 학생 배려)
- "단어 숨기기" 옵션: 익숙해지면 색·화살표만으로 반응하는 도전 모드 (기본값은 단어 표시)
- 사용 방식: **혼자, 바닥에 세운 자기 태블릿 앞에서** 신호에 따라 섀도 동작
- 시작 버튼 → 3초 카운트다운 → 신호 시작, 라운드가 끝나면 자동 정지
- 설정: 라운드 시간(60 / 90 / 120초), 휴식 시간, 신호 간격(2~5초)
- 기본은 무음. 효과음은 켜기 옵션으로만 둔다. (30대 동시 사용 시 혼란 방지)
- **가드 복귀 측정**: 기능 1의 내 가드 등록이 되어 있으면, 라운드 중 카메라로 조용히 측정한다.
  - 신호 화면을 깔끔하게 두기 위해 **라운드 중에는 경고를 띄우지 않는다.**
  - 공격 신호(잽·스트레이트·원투) 후 1.5초 안에 가드로 돌아온 비율 = **가드 복귀율** (초기값)
  - 더킹 신호 직후 1.5초는 측정에서 제외한다.
  - 라운드 끝에 가드 복귀율을 보여 준다.
- **AI 동작 판정 (동작 점수)**: 카메라로 신호대로 움직였는지 판정한다. 내 가드 등록이 없어도 쓸 수 있다. (기본 켜짐, 끌 수 있음)
  - 시작 전에 **내 앞손**을 고른다: 왼손이 앞(오른손잡이) / 오른손이 앞(왼손잡이). 잽 = 앞손, 스트레이트 = 뒷손. 태블릿에 기억한다.
  - 신호 직전 0.4초 자세를 기준으로, 신호 뒤에 무엇이 움직였는지 본다. 펀치 = 손목이 얼굴에서 멀어짐, 슬립 = 머리가 엉덩이 기준으로 옆으로 이동(좌우 스텝은 제외), 더킹 = 머리가 내려감.
  - 원투는 앞손 → 뒷손 순서까지 본다. 잽 신호에 원투를 치면 오답.
  - 라운드 중: 맞으면 ✓ "좋아요!", 틀리면 ✗ "보인 동작: …"을 아래쪽에 잠깐 보여 주고, 위쪽에 정답 수/판정 수를 표시한다. 새 신호가 나오면 앞 판정 글자는 지운다.
  - 몸이 잘 안 보인 신호는 "판정 불가"로 점수 계산에서 뺀다.
  - 결과: **동작 점수**(정답 비율), **평균 반응 시간**(신호 → 맞게 움직이기 시작), **동작별 정확도**, 가장 약한 동작에 맞춘 연습 팁

### 기능 3: 차시 자기점검 기록 + 결과 복사
- 학번 입력(이름 없음), 체크리스트 5문항(가드 유지, 턱 당기기, 펀치 후 가드 복귀, 팔꿈치 붙이기, 스탠스)과 소감 한 줄
- 기능 1의 손·팔꿈치 유지율, 기능 2의 동작 점수·평균 반응 시간·동작별 정확도·가드 복귀율은 자동 입력
- 태블릿 안(localStorage)에 차시별로 저장하고 이전 차시와 비교해 보여 준다.
- "결과 복사" 버튼 → 요약 텍스트를 구글 폼·클래스룸에 붙여 넣어 제출

### 화면 구성
1. 홈: 가드 체크 / 섀도 반응 콜러 / 내 기록 + 안전 수칙 한 줄
2. 설치 확인 (기능 1·2 공통)
3. 내 가드 등록
4. 가드 체크 라운드 → 결과
5. 콜러 설정(레벨·라운드·내 앞손) → 콜러 라운드(✓/✗) → 결과(동작 점수·반응 시간·동작별 정확도·가드 복귀율)
6. 자기점검 입력 → 기록 비교 → 결과 복사

### 차시 운영 예시
- **1차시 (가드)**: 스탠스·가드 설명 → 설치·등록 → 가드 체크 R1 서서 유지(30초) → R2 가드 유지하며 **좌우 스텝**(30초) → R3 잽 뻗고 가드 복귀(60초) → 자기점검 기록
- **2차시부터 (반응)**: 설치·등록 → 가드 체크 1라운드로 준비 → 섀도 반응 콜러 레벨 1→3 → 자기점검 기록

## 4. Out of Scope (지금은 안 만든다)
- 지연 거울 → 2차 버전 (개인 사용에서는 가드 체크와 역할이 겹침)
- 루틴 창작기 (URL·QR 공유) → 2차 버전
- 짝 활동 기능, 교사용 TV 모드, 음성 합성 호출
- 영상 녹화·저장·다운로드
- 로그인, 학생 명단 관리, 교사용 집계 화면
- 앱 판정만으로 수행평가 점수 산출 (유지율·동작 점수는 참고 자료로만 사용)
- 펀치의 질(주먹 모양, 허리 회전, 체중 이동) 판정
- 턱 들림, 주먹이 얼굴 앞으로 나오는 미세한 차이 판정 (정면·바닥 카메라로는 어려움 → 교사 관찰)

## 5. 사용 환경 / 제약
- 디바이스: Windows 태블릿 PC, Edge/Chrome, 가로 화면, 큰 터치 버튼
- 네트워크: 학생 태블릿에서 GitHub Pages 접속 확인 완료. 첫 접속 후 오프라인에서도 동작하도록 캐시
- 로그인/인증: 없음
- 개인정보:
  - 카메라 영상은 저장·전송하지 않는다. 자세 인식은 태블릿 안에서만 처리한다. (카메라 사용 가능 확인 완료)
  - MediaPipe 라이브러리의 사용 통계 전송은 CSP(connect-src)로 막는다. 허용 주소는 자기 사이트와 모델 파일 주소뿐.
  - 기록에는 학번만 입력, 태블릿 안에만 저장
  - 코드에 학생 정보를 넣지 않는다.
- 운영 안전:
  - 장비 없이 비접촉 섀도복싱만 한다. 화면을 향해 치지 않는다.
  - 바닥 태블릿 앞에 서는 자리를 테이프·콘으로 표시해 밟지 않게 한다.
  - 학생 간 팔 길이 이상 간격을 둔다.
  - 스텝은 좌우로만 한다. (앞뒤 스텝은 태블릿에 다가가 위험하고 판정도 흔들림)

## 6. 성공 기준
- 수업 시작 후 3분 안에 전원이 QR로 접속해 첫 활동을 시작한다.
- 테스트에서 바른 가드를 30초 유지할 때 오경보가 1회 이하이다.
- 손을 어깨 아래로 내리면 1~2초 안에 경고가 뜬다.
- 교사가 표시 자리에서 신호대로 정확히 동작했을 때 동작 점수 80% 이상, 가만히 서 있을 때 ✓가 나오지 않는다.
- 학생이 가드 체크 결과를 보고 자기 약점(손/팔꿈치)을 말할 수 있다. (교사 관찰)
- 차시 자기점검 제출률 90% 이상

## 7. 기술 스택 / 배포
- 언어·프레임워크: **React 19 + Vite + TypeScript + Tailwind CSS 4**
  - 애니메이션: motion, 아이콘: lucide-react
  - 화면 전환은 라우터 없이 상태(state)로 처리 (GitHub Pages 새로고침 404 문제 회피)
- 자세 인식: `@mediapipe/tasks-vision` Pose Landmarker(lite 모델)
  - WASM 파일과 모델 파일을 `public/` 폴더에 넣어 저장소에서 직접 제공 (외부 서버 의존 없음)
  - 판정은 초당 약 15회, 카메라 해상도는 낮춰서 태블릿 부담 감소. 인식이 느린 태블릿에서는 간격을 자동으로 늘린다.
- 오프라인: vite-plugin-pwa로 서비스 워커·캐시 구성
- 외부 API·DB 없음
- 배포: GitHub Pages + GitHub Actions 자동 빌드·배포, `vite.config`의 `base`를 저장소 이름으로 설정, 주소는 QR로 배포
- 폴더 구조(안)
  - `src/screens/` 화면별 컴포넌트
  - `src/pose/` 카메라·자세 인식·가드 판정 로직
  - `src/caller/` 신호 생성·라운드 타이머
  - `src/storage/` localStorage 기록 관리
- **만드는 순서**
  1. 가드 체크 테스트 버전 (설치 확인 + 내 가드 등록 + 라운드 판정)
  2. 교사가 학생 태블릿으로 체육관 바닥 배치 테스트 → 기준값(손 0.3 / 팔꿈치 0.15 / 1초 / 1.5초) 조정
  3. 섀도 반응 콜러 + 가드 복귀 측정 + AI 동작 판정(앞손 설정) → 체육관에서 `JUDGE` 기준값 조정
  4. 자기점검 기록 + 결과 복사
  5. 오프라인 캐시·GitHub Pages 배포

## 8. 미해결 질문
- 대상 학년과 차시 수 (기본값: 중학생, 3~4차시)
- 훅·어퍼컷 포함 여부 (현재: 잽, 스트레이트, 원투, 슬립, 더킹)
